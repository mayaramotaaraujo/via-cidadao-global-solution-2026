# Modelo do termo de consentimento para gravação de voz

Projeto: **Zelo, assistente de voz para zeladoria urbana**
FIAP, Global Solution 2026.2, disciplina Processamento de Linguagem Natural, Chatbots & Virtual Agents

Cada pessoa que gravou áudios de teste concordou com os pontos abaixo:

1. As frases são fictícias e não contêm dados pessoais.
2. A voz é um dado pessoal e pode ser considerada dado biométrico (LGPD, Lei 13.709/2018).
3. Os áudios são usados apenas para medir a taxa de erro da transcrição (WER) e analisar diferenças de desempenho entre vozes, e ficam no repositório como evidência para a avaliação acadêmica.
4. Cada falante aparece apenas por um código (F1, F2 ou F3), sem nome, nos resultados.
5. A voz não é usada para treinar modelos nem para clonagem de voz.
6. Qualquer falante pode pedir a exclusão dos seus áudios a qualquer momento.
