Integrantes: Mayara Mota (RM 563887) e Gabriel Palmeira (RM 563522).

Fluxo: som, microfone do celular, Audio (MFE), CNN, classificação e resposta visual no celular (Edge Impulse).

Pastas:
* `docs/guia_passo_a_passo.md`: o que fazer no celular e no Edge Impulse
* `docs/roteiro_video.md`: roteiro do vídeo
